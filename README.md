# Worktrees

A local dashboard for Git worktrees, branches, and recent commits.

Install Node.js 22 or later and Git, then run:

```sh
npx @0001-labs/worktrees
```

The dashboard opens at `http://localhost:4777`. On macOS, choose **Add project** to select a Git repository.
